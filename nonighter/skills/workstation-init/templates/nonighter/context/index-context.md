# Context — index

> The first direction: every source of material this instance reads from, what each is for, and where to go next. Read on demand, before looking for any document, model or folder. Written only by the daily conformance run.

Retrieval path: this file → a lower index where one exists → the card → the file itself. **Never walk the estate.** How this system works and how a card is written: `context/instructions-context.md`. What a tag means: `context/tag-dimensions.md`.

Everything this system holds lives inside `.nonighter/context/`. Nothing is written into the folders described here.

## What each source is for

*Empty at install.* One short paragraph per source: what the material is, what a session would come here for, and anything about it that is not obvious from the folder names. This is the part that makes this file a first direction rather than a routing table — a session should be able to choose a source from what is written here, without opening anything.

## Coverage

*Empty at install.* What has actually been read, so a gap is visible rather than assumed away: per source, how deep the mapping went, how many cards exist, and what was deliberately left undescribed.

A source registered but not yet mapped says so here. **An unmapped source is not a described source**, and a session that treats this index as complete when it is not will conclude the material does not exist.
