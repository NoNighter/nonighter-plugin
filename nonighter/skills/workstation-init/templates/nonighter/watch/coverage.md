That is deliberate: coverage inferred from the folder contents or from the client names in the memory files produces a confident report about the wrong universe, and it reads as though someone chose it.

The install asks for a starter - two or three names and a sector, enough to make the first run
useful. Widen it from there, in the user's own words. Group it however they think about it: the run
files follow this file's grouping.
